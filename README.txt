EXPERIMENT 8 — GIT BRANCHING, MERGING, CONFLICT RESOLUTION AND TAGGING
Requirement: Git installed. Open Terminal in this experiment folder and run the commands in commands.sh one by one (do not blindly rerun the whole script after partial completion).
Expected observations: branches main, feature1 and feature2; feature1 merges; feature2 merge creates a conflict; after replacing conflict markers and committing, git tag lists v1.0. Capture your own Terminal output. If git asks for identity, configure your own name/email using git config --global user.name "Your Name" and git config --global user.email "you@example.com".
